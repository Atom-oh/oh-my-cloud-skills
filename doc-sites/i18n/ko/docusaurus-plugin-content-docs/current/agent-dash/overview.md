# agent-dash

Claude에게 묻지 않고도 Claude Code 세션의 어떤 에이전트가 일하고 있는지, 누가 누구에게
일을 맡겼는지, 어느 에이전트가 어느 에이전트를 기다리고 있는 것으로 보이는지 확인합니다.
Claude Code에서 `agent-dash`는 mod로, 패널, 프롬프트 위의 한 줄 밴드, 상태 줄, 알림을
제공합니다. 화면을 그릴 수 없는 Codex 등에서는 `agent-status` 스킬이 에이전트 팀 명단을
텍스트로 알려 줍니다.

## 보여 주는 내용 {#what-it-shows}

패널은 세션의 서브에이전트, 팀원, 워크플로 에이전트를 위임 관계 트리로 나열합니다. 각 행에는
에이전트 이름, 유형, 상태, 그 상태로 머문 시간이 표시됩니다. 기다리는 중인 에이전트의 행에는
`waits on <agent> (est.)`가 추가됩니다. 각 행의 `open` 버튼은 해당 에이전트의 대화를 메인
화면에서 엽니다. `3 running · 1 waiting (est.) · 2 done` 같은 요약 줄은 상태 줄과 프롬프트 위
밴드에도 나타납니다.

대기는 추정입니다. agent-dash는 생성 이벤트와 메시지 이벤트로 대기를 추론합니다. 부모는
포그라운드로 시작한 자식을 기다리고, 보낸 쪽은 상태가 바뀌지도 답하지도 않은 메시지 대상을
기다립니다. 엔진이 이런 사실을 알려 주지는 않으므로 모든 화면에 `est.`를 붙입니다. 자체 터미널
패널에서 실행되는 팀원은 세션 안에 루프가 없어서 상태가 오래된 값일 수 있습니다.

## 동작 방식 {#how-it-runs}

`/agent-dash`로 패널을 열고, `/agent-dash stop`으로 감시를 멈추고 상태 줄을 지웁니다. mod는
5초마다, 그리고 에이전트가 생성되거나 메시지가 전송되거나 턴이 끝날 때 갱신합니다. 에이전트가
끝나거나 실패하거나 중지되었을 때, 그리고 대기가 `longWaitMs`(기본 120000)보다 길어졌을 때
알림을 띄웁니다. 화면을 그릴 수 없는 VS Code 채팅 패널과 `claude -p`에서는 `/agent-dash`가
요약을 텍스트로 돌려줍니다.

## 모델 정책 {#model-policy}

선택 사항인 정책으로 서브에이전트 생성의 모델을 정할 수 있습니다. 기본값은 꺼짐입니다.
`modelPolicyEnabled`를 켜면 모델을 지정하지 않은 생성에 `modelPolicyMap`(서브에이전트 유형을
`opus`, `sonnet`, `haiku`에 대응시킨 JSON 객체)이 그 유형에 지정한 별칭이 적용됩니다. 비워 두면
저장소의 역할별 등급을 따르는 내장 매핑을 씁니다. 호출에서 지정한 모델과 세션이 모든
서브에이전트에 강제한 모델은 항상 정책보다 우선합니다. agent-dash가 무언가를 바꾸는 곳은
여기뿐입니다.

## 한계 {#limits}

agent-dash는 관찰만 합니다. 도구 호출이나 프롬프트를 승인·거부·수정하지 않으며, 에이전트끼리
주고받는 메시지도 바꾸지 않습니다. 행의 버튼은 화면만 전환합니다. mod는 Claude Code 안에서
내 권한으로 실행되는 코드입니다. `claude plugin validate`가 처리하는 모든 이벤트를 나열하고,
`--safe-mode`로 끌 수 있습니다. 조직의 `allowManagedModsOnly` 설정은 관리되지 않는 마켓플레이스에서
설치한 mod를 차단합니다.

## 시작하기 {#get-started}

`/plugin install agent-dash@oh-my-cloud-skills`로 설치하고 새 세션을 시작합니다. mod에는 Claude
Code 2.1.300 이상이 필요합니다. Codex에서는 스킬 선택기에서 `agent-dash:agent-status`를
선택합니다. 에이전트 팀 명단과 작업 파일을 읽어 아무것도 바꾸지 않고 보고합니다. 소스는
`plugins/agent-dash/`에 있습니다.
