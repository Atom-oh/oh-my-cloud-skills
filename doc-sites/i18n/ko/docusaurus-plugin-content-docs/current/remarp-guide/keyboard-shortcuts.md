# 키보드 단축키

아래 기본값은 현재 `SlideFramework.getKeyAction()` 구현을 기준으로 합니다. 덱에서 자체 키·동작 매핑으로 재정의할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| Right, Space, PageDown | 다음 내용을 단계별로 표시한 뒤 다음 슬라이드로 이동 |
| Left, PageUp | 지원되는 경우 이전 단계의 내용을 숨긴 뒤 이전 슬라이드로 이동 |
| Down / Up | 등록된 슬라이드 동작, 상호작용 항목 순환, 단계별 표시·슬라이드 탐색 순서로 처리 |
| Home / End | 첫 / 마지막 슬라이드 |
| N | 발표자 보기(노트) 열기 |
| F | 전체 화면 전환 |
| G | 전체 보기 전환 |
| S | 전체 화면이 아닐 때 사이드바 전환 |
| T | 덱 전체의 다크/라이트 테마 전환(`@theme`으로 고정한 슬라이드는 유지). 선택은 이 브라우저에만 저장됩니다 |
| H | 현재 슬라이드 숨기기/해제. 방향키와 Space는 숨긴 슬라이드를 건너뛰고, 사이드바(썸네일의 눈 아이콘), 전체 보기, 검색, `#N`으로는 계속 이동할 수 있습니다. 발표자 창에는 슬라이드 숨기기 버튼이 있습니다. 선택은 이 브라우저에만 저장됩니다 |
| Escape | 펜 모드가 켜져 있으면 펜 모드 종료, 아니면 전체 보기 종료, 그 외에는 전체 화면 종료 |

input이나 textarea에 입력하는 동안에는 덱 탐색이 실행되지 않습니다. 덱을 터치 스와이프하여 이전·다음으로 이동할 수 있습니다. Compare/tabs/Canvas 동작은 해당 슬라이드에 등록된 상호작용에 따라 달라집니다.

## 사용자 지정 매핑 {#custom-mappings}

```yaml
keys:
  n: next
  Backspace: prev
```

런타임은 키·동작 매핑 객체를 읽습니다. 탐색 분기문에 구현된 동작만 지원합니다. 숫자 1-9와 펜 글자 P, O, I, U, Y, C는 펜이 먼저 처리하므로 매핑해도 효과가 없습니다. N은 이미 발표자 보기, G는 전체 보기를 엽니다(위의 `n: next` 예제는 N의 기본 동작을 대체합니다). 기본 매핑에는 화면 암전용 B가 없으며, 이를 나열한 과거 예제는 현재 런타임 명세가 아닙니다.

## 펜 모드 {#pen-mode}

발표 중 슬라이드 위에 그릴 수 있습니다. 모든 펜 키는 Option/Alt와 Shift 없이 누르는 일반 키이며 QWERTY 키 위치 기준이므로 Dvorak이나 AZERTY 계열 배열에서는 해당 위치의 키를 누릅니다(숫자는 숫자 행 위치). 한글·일본어 IME가 켜져 있어도 동작하고, 텍스트 입력란에 포커스가 있으면 무시됩니다. N, G, F, S, H, T, Space와 방향키는 기존 기능을 그대로 유지합니다.

| 키 | 동작 |
| --- | --- |
| P | 레이저: 꺼져 있으면 레이저로 켜기, 다른 모드로 켜져 있으면 레이저로 전환, 레이저로 켜져 있으면 끄기 |
| O | 펜 (켜진 상태 유지) |
| I | 형광펜 (반투명, 넓은 선, 켜진 상태 유지) |
| U | 지우개 (획 단위로 삭제) |
| Y | 돋보기: 원형 렌즈가 마우스를 따라감 (켜진 상태 유지) |
| C | 현재 슬라이드의 모든 잉크 지우기 |
| 1 / 2 / 3 | 얇게 / 보통 / 굵게, 돋보기 모드에서는 2배 / 3배 / 4배 확대 |
| 4 / 5 / 6 / 7 / 8 / 9 | 빨강 / 노랑 / 초록 / 파랑 / 흰색 / 검정, 돋보기 모드에서는 동작 없음 |
| Esc | 펜 모드 종료 |

O, I, U, Y는 펜 모드가 꺼져 있으면 각각 펜 모드를 켭니다. 잉크 지우기는 C입니다. 숫자 1-9는 항상 펜이 사용하므로 덱에서 다른 동작으로 다시 매핑할 수 없습니다. 기본값은 빨강과 보통 굵기이며, 형광펜의 기본 색은 노랑입니다. 레이저, 펜, 형광펜은 각각 자신의 색을 기억합니다. Esc는 펜 모드를 종료하며, 펜 모드가 켜져 있는 동안에는 열려 있는 아젠다나 상세 패널보다 우선합니다. Chrome과 Edge에서 F 키로 전체 화면에 들어가면 Esc가 페이지로 전달되도록 고정됩니다. 첫 번째 Esc는 펜 모드를 종료하고(또는 전체 보기를 닫고), 다음 Esc는 전체 화면을 종료하며, Esc를 길게 누르면 언제든 전체 화면이 종료됩니다. 이 고정에는 보안 컨텍스트(https 또는 localhost)가 필요하므로 `file://`로 연 덱에서는 적용되지 않을 수 있습니다. 포커스가 폼 컨트롤(범위 입력, 텍스트 필드, 임베드된 iframe)에 있으면 고정된 전체 화면에서 Esc가 아무 동작도 하지 않으므로, Esc를 길게 누르거나 먼저 슬라이드 배경을 클릭한 뒤 종료합니다. 브라우저 메뉴나 Cmd+Ctrl+F, F11로 들어간 전체 화면은 이 고정의 영향을 받지 않으며, 그곳에서 Esc가 페이지로 전달되는지는 브라우저에 따라 다릅니다(확인하지 않음). Safari와 Firefox에서는 Fullscreen API 전체 화면의 Esc가 페이지에 전달되기 전에 전체 화면을 종료합니다. P는 언제나 펜 모드를 종료하며, 펜, 형광펜, 지우개, 돋보기 상태에서는 한 번 더 누르면 먼저 레이저로 전환됩니다.

펜 모드가 켜져 있는 동안에는 캔버스가 슬라이드 위의 모든 포인터 입력을 받으므로, 탭, 퀴즈 버튼, 비교 토글, 상세 툴팁은 펜 모드를 끈 뒤에 사용합니다.

레이저 획은 3초 뒤에 사라집니다. 펜과 형광펜 잉크는 세션 동안 해당 슬라이드에 남고 저장되지 않습니다. 잉크는 덱 창과 발표자 창 팝업(N으로 열기) 사이에서 미러링됩니다. 발표자 창의 현재 슬라이드 미리보기에 그린 잉크는 덱 창의 같은 슬라이드 위치에 표시되며, 별도의 덱 창이나 탭끼리는 슬라이드 위치만 동기화됩니다.


`SlideFramework` 옵션의 `pen: { fadeMs, audienceBadge }`로 레이저 사라짐 시간(기본 3000ms)을 바꾸거나 `audienceBadge: false`로 덱 창의 모드 배지를 숨길 수 있습니다. 발표자 창에는 항상 배지가 표시됩니다.

### 돋보기 {#magnifier}

Y를 누르면 돋보기가 켜집니다. 슬라이드 높이의 28% 크기인 원형 렌즈가 마우스를 따라다니며 그 아래의 슬라이드를 확대해 보여 줍니다. 확대 배율은 2배로 시작하며, 1, 2, 3으로 2배, 3배, 4배를 선택하고 배지에 현재 배율이 표시됩니다. 가장자리 근처에서는 렌즈가 슬라이드 안에 머물지만 렌즈 중심에는 여전히 마우스 아래의 지점이 표시됩니다.

렌즈는 덱 창과 발표자 창 사이에서 미러링됩니다. 발표자 창의 현재 슬라이드 미리보기를 가리키면 덱 창의 같은 슬라이드 위치에 렌즈가 표시되고, 덱 창을 가리키면 미리보기에 렌즈가 표시됩니다. 발표자 창을 닫아도 덱 창의 렌즈는 계속 동작합니다. 마우스가 슬라이드를 벗어나거나, 모드를 바꾸거나, 슬라이드를 넘기거나(마우스를 다시 움직일 때까지), 전체 보기로 들어가면 렌즈가 숨겨집니다.

돋보기 모드에서는 클릭과 호버가 슬라이드에 전달되지 않습니다. P, O, I, U는 모드만 바꾸고 펜 모드는 켜 둔 채로 두므로, 캔버스가 계속 모든 포인터 입력을 받습니다. 클릭과 호버는 펜 모드를 끈 뒤에만 슬라이드에 전달됩니다. Esc가 페이지로 전달되는 환경에서는 Esc를 누르거나 P를 두 번 누릅니다(첫 번째는 레이저로 전환하고, 두 번째는 펜 모드를 끕니다).

렌즈에는 다음과 같은 제한이 있습니다.

- 슬라이드만 확대됩니다. 푸터, 로고, 진행 표시줄은 확대되지 않습니다.
- 펜 잉크는 비트맵으로 렌즈에 복사되므로 3배와 4배에서는 흐릿하게 보입니다.
- 캔버스 애니메이션은 매 프레임 렌즈에 복사됩니다. 렌즈 안의 iframe은 별도 사본으로 다시 로드되고, 동영상은 포스터나 첫 프레임만 표시합니다.
- 렌즈는 슬라이드 전환, 프래그먼트 표시, 슬라이드 안의 `class` 변경, 창 크기 변경 때 갱신됩니다. 텍스트, `style`, `hidden`만 바꾸는 변경은 다음 슬라이드 전환이나 창 크기 변경 전까지 렌즈에 반영되지 않습니다.
- `fill="url(#grad)"`나 `<use href="#sym">` 같은 SVG 참조는 참조 대상이 슬라이드 안에 있으면 두 창 모두에서 표시됩니다. 슬라이드 밖의 요소를 참조하면 덱 창의 렌즈에는 표시되지만 발표자 창의 렌즈에는 표시되지 않습니다.

## 발표자 보기와 전체 보기 {#presenter-and-overview}

보조 화면으로 발표하기 전에 N을 눌러 창 동기화를 확인합니다. G를 눌러 전체 보기를 열고 이동할 슬라이드를 선택합니다. 특히 기본 키를 바꾸는 경우에는 실제 생성된 덱에서 사용자 지정 키 매핑을 테스트합니다.

## 단계 안내와 아래 화살표 표시 {#step-cue}

발표자 창은 화살표 버튼 아래의 상태 상자에 현재 슬라이드에서 다음 Down 키가 하는 일을 알려 줍니다. ↓ 다음 단계 있음 (지금 n/N), ✓ 마지막 단계 (N/N), 누르면 다음 슬라이드, ✓ 단계 없음, 누르면 다음 슬라이드, 프래그먼트가 남아 있으면 → 다음 항목 있음 (n/N), 장면이 단계 수를 알려 주지 않으면 ↓ 이 장에 단계가 있음이 표시됩니다. 덱의 `lang`이 `ko`로 시작하면 한국어, 그 밖에는 영어로 표시됩니다. 슬라이드 전환, 두 창 어디에서든 누른 키, 장면 자체의 이전/다음 버튼에 맞춰 갱신됩니다.

노트 영역에서는 발표 대본의 `↓`가 주황색 배지로 그려집니다. 슬라이드가 소비하는 키 입력 한 번마다 `↓`를 정확히 하나씩, 단계를 끝맺는 문장 바로 뒤에 적습니다(퀵 체크는 하나로 셉니다). "아래 화살표를 누르겠습니다"처럼 무엇을 누를지 대본에 쓰지 않으며, `[요약]`, `[출처]`, `[약어]` 줄과 그 바로 아래 목록, `{...}` 마커 안에는 `↓`를 넣지 않습니다. Remarp 원본과 내보낸 PDF에는 일반 문자가 그대로 남습니다.

## 발표자 노트 편집 {#edit-speaker-notes}

발표자 창의 Speaker Notes 영역을 직접 편집할 수 있습니다. **Edit notes** 버튼을 누르거나 노트를 더블클릭해 내용을 고친 뒤 Ctrl+Enter(Cmd+Enter)를 누르거나 **Save notes**를 누릅니다. 입력 상자를 벗어나도 저장되고, Esc는 취소합니다. 저장한 내용은 원래 노트와 같은 서식으로 표시됩니다. 수정한 슬라이드에는 **Edited** 배지와 **Reset to original** 버튼이 나타납니다.

수정 내용은 이 브라우저에만 슬라이드별로, 원본 노트와 다를 때만 저장됩니다. Remarp 원본과 청중 창은 바뀌지 않으며, 큐와 타이밍은 원본 값을 유지합니다. 입력 상자에 포커스가 있는 동안 단축키와 방향키는 동작하지 않고 글자로 입력됩니다. 편집 중에 슬라이드를 넘기거나 발표자 창을 닫으면 먼저 저장됩니다.
