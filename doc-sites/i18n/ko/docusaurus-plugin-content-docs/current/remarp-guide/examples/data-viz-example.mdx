# 데이터 시각화 예제

이 예제는 문법과 렌더링 패턴을 설명합니다. 새 덱에는 현재 [Canvas 정책](/docs/remarp-guide/syntax/canvas-dsl)과 [테마 토큰](/docs/remarp-guide/themes/css-variables)을 적용합니다. 규모가 크거나 그룹이 있는 아키텍처에는 HTML/CSS를 사용합니다. 예제 지표는 설명용입니다.

Remarp에서 KPI 카드, 차트와 대시보드 레이아웃을 활용하는 데이터 시각화 기법을 설명합니다.

## 디자인 시스템 원칙 {#design-system-principles}

### 글자 계층 {#typography-hierarchy}

| 요소 | 크기 | 굵기 | 용도 |
|---------|------|--------|----------|
| 대표 통계 | 3.5rem+ | 700 | 핵심 지표 하나를 강조 |
| KPI 값 | 2.4rem | 700 | 대시보드 카드 값 |
| 카드 제목 | 1.1rem | 600 | 섹션 제목 |
| 본문 | 1rem | 400 | 설명 |
| 레이블 | 0.85rem | 500 | 축 레이블, 캡션 |

### 의미별 색상 {#semantic-colors}

| 목적 | 변수 | 용도 |
|---------|----------|-------|
| 긍정 | `--green` (#00b894) | 상승 추세, 성공 |
| 부정 | `--red` (#e17055) | 하락 추세, 오류 |
| 경고 | `--yellow` (#fdcb6e) | 알림, 대기 |
| 주요 강조 | `--accent` (#6c5ce7) | 핵심 지표 |

## 권장 사항 {#best-practices}

1. **의미별 색상을 사용합니다** — 긍정은 녹색, 부정은 빨간색으로 일관되게 표시합니다.
2. **데이터 밀도를 제한합니다** — 슬라이드당 KPI 카드는 최대 4-6개로 제한합니다.
3. **맥락을 제공합니다** — 추세, 비교나 기간을 표시합니다.
4. **반응형 그리드를 사용합니다** — `auto-fit`과 `minmax()`로 유연한 레이아웃을 구성합니다.
5. **점진적으로 표시합니다** — `data-fragment-index`로 대시보드를 단계별로 보여 줍니다.
6. **글자 스타일을 통일합니다** — 글자 크기는 계층 표를 따릅니다.
7. **다크 테마를 고려합니다** — 색상을 직접 고정하지 말고 CSS 변수를 사용합니다.
