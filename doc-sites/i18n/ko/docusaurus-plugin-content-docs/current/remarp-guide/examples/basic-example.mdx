## 확인할 사항 {#what-to-inspect}

실행 데모는 결과물 참고용으로 사용하고, 현재 영문 소스는 [빠른 시작 예제](../quick-start.md)를 확인합니다. 문법 기능별로 전용 가이드가 있습니다. 삽입된 고정 소스는 과거의 언어, 스타일이나 런타임 동작을 사용할 수 있습니다.

예제 프로젝트는 `_presentation.md`에서 언어 설정을 읽으며, 명령은 별도 출력 디렉터리에 결과를 기록합니다. 삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
