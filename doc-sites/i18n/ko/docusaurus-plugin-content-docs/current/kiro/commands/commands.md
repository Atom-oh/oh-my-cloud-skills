# Kiro 명령어

## /kiro:setup {#kiro}

Kiro CLI를 감지하고 시험하며 사용 가능한 모델 설정을 확인한 뒤 구현자, 검토자, 선택적 검색 에이전트를 준비합니다. 설정 과정은 기본 위임, 커밋·푸시 검토, 웹 검색, 셸 도구 사용 동의를 각각 분리합니다.

## /kiro:delegate {#kiro-1}

구체적인 구현 요청이나 승인된 계획을 제공합니다. 호스트가 계획하고 Kiro가 작업 트리에서 구현하며, 호스트가 캡처한 변경과 테스트를 검증한 뒤 커밋합니다. 결과에는 위임 내용과 호스트 구현으로 전환한 작업을 보고합니다.

## /kiro:review {#kiro-2}

선택적 훅과 동일한 검토 엔진으로 요청한 범위를 검토합니다. 의심되는 문제를 코드와 설정에 대조해 확인합니다. 잘못된 검토자 에이전트 설정이 도구 접근 권한을 조용히 넓혀서는 안 됩니다.

## /kiro:configure {#kiro-3}

실제 적용 설정과 출처를 표시하거나 지원되는 위임, 검토, 웹 검색 필드를 갱신합니다. 기본 설정의 모델은 null일 수 있으며 설정 과정에서 결정됩니다. 오래된 모델 이름을 복사하지 말고 실제 설정을 사용합니다.

[정확한 키 및 기본 설정](https://github.com/Atom-oh/oh-my-cloud-skills/blob/main/plugins/kiro/skills/kiro-delegate/kiro.defaults.json)

커밋·푸시 훅은 사용자가 선택해 켜는 로컬 통제입니다. 저장소의 필수 CI, 검토 범위, 브랜치 보호는 계속 별도로 적용됩니다. Codex는 명령 워크플로를 생성된 스킬로 제공합니다.
