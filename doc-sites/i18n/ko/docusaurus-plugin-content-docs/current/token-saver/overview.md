# token-saver

대화 답변은 짧게 유지하면서 요청한 작업은 완전하게 수행합니다. `token-saver`는
Claude Code와 Codex에 동일한 영문 응답 지침을 제공합니다.

## 달라지는 점 {#what-changes}

유용한 결과부터 답하고 서론, 질문 반복, 불필요한 재요약, 추가 설명 권유를
생략합니다. 일반적인 분석, 리뷰, 비교, 요약 요청에도 짧게 답합니다.

완성된 코드·파일·문서, 요청한 절차, 자세한 답변, 필수 리뷰나 CI 형식은 필요한
길이와 구조를 유지합니다. 중요한 발견, 위험, 한계, 추론과 검증도 작업에
계속 포함됩니다.

## 작동 방식 {#how-it-runs}

호스트가 해당 이벤트를 실행할 때 단일 `SessionStart` 명령이 패키지의 지침을
추가합니다. 추가 모델 호출, 대화 기록 읽기, 사용자·프로젝트 설정 변경은
수행하지 않습니다. 자동 훅을 사용할 수 없을 때는 수동 `concise-responses`
스킬로 같은 지침을 적용합니다.

## 한계 {#limits}

지침 자체가 소량의 입력 문맥을 추가합니다. 강제 토큰 예산을 설정하거나
선택한 모델·추론 강도를 바꾸지 않으며, 요금 절감을 보장하지 않습니다.
실제 동작은 모델, 작업, 명시적인 요청과 다른 적용 지침에 따라 달라집니다.
훅 지원과 신뢰 여부는 호스트가 제어합니다.

## 시작하기 {#get-started}

[설치 및 검증](installation.md)을 참고하세요. 관리되는 지침과 훅은
`plugins/token-saver/`에 있으며, 두 호스트용 패키지 모두 이 마켓플레이스에
포함됩니다.
