# Well-Architected 검토

6개 핵심 요소를 기준으로 아키텍처를 평가하고 점수와 근거를 갖춘 개선 로드맵을 작성합니다.

## 워크플로 {#workflow}

아키텍처와 워크로드의 맥락을 수집하고 각 핵심 요소를 검토합니다. 기준 평가표를 사용해 점수를 산정하고 심각도를 검증합니다. 현재 설계와 목표 설계를 설명한 뒤 조치와 측정 가능한 결과의 우선순위를 정합니다.

## 대상 범위 {#coverage}

운영 우수성, 보안, 안정성, 성능 효율성, 비용 최적화, 지속 가능성을 다룹니다.

## 보고 및 경계 {#reporting-and-boundaries}

보고서에는 핵심 요소별 점수, 근거의 공백, 확인된 발견 사항, 빠른 수정, 큰 규모의 변경, 의존 관계, 검증을 포함합니다. 근거 부족과 입증된 실패를 구분하고 범위 밖의 영역을 명시합니다.

소스 스킬에는 명령별 실행 절차, 의사결정 트리, 예제, 참조 파일, 호스트·팀 연동이 포함되어 있습니다. 수행할 작업의 정확한 절차는 소스 스킬에서 확인합니다.
