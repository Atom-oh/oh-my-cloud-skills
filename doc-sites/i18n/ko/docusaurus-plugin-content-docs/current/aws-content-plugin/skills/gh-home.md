반응형 개인 프로필이나 개발자 포트폴리오를 하나의 HTML 페이지로 만듭니다.

## 페이지 구조 {#page-structure}

사이드바에 사진, 이름과 링크를 배치하고 소개, 경력 타임라인, 기술, 대표 작업과 프로젝트 소개를 구성합니다. 제공된 사실과 에셋을 사용하며 경력, 자격이나 프로젝트 성과를 지어내지 않습니다.

## 작업 흐름 {#workflow}

승인된 프로필 내용을 모으고 관련 작업을 선택해 페이지를 만듭니다. 반응형 탐색과 링크를 테스트하고 콘텐츠 리뷰를 수행한 뒤 승인된 GitHub Pages 게시를 진행합니다. 제품·솔루션 페이지에는 brochure를 사용합니다.
