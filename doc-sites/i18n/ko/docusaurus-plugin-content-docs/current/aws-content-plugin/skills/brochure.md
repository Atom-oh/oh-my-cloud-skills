가치 제안, 기능 설명, 아키텍처와 행동 유도 문구를 담은 반응형 제품·솔루션 소개 페이지를 단일 파일로 만듭니다.

## 작업 흐름 {#workflow}

대상 독자와 유도할 행동을 정하고 간결한 문구를 작성합니다. 편집 레이아웃을 구성하고 아키텍처를 삽입한 뒤 데스크톱·모바일 렌더링, 링크와 제어 기능을 테스트합니다. 콘텐츠 리뷰를 거쳐 사용자가 승인한 범위에서만 게시합니다.

스킬의 참고 레이아웃, 에셋과 도구 스크립트를 사용합니다. 개인 프로필은 gh-home, 슬라이드 덱은 reactive-presentation, 여러 페이지로 된 문서는 GitBook을 사용합니다. 독자의 의사결정에 도움이 되는 경우에만 구현 세부 사항을 설명합니다.
