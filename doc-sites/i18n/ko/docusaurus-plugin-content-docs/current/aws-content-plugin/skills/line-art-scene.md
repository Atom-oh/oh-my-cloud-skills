# 선화 장면 스킬

키를 누를 때마다 한 단계씩 흐름을 설명하는 손그림 장면을 만듭니다. 움직이는 카메라, 실제 경로를 따라가는 패킷, 번호 콜아웃, 작은 선화 인물, 측면 패널이 들어갑니다.

## 사용 시점 {#when-to-use-it}

요청 경로, 파이프라인, 프로토콜을 여러 단계로 설명할 때 씁니다. 섹션 시작의 간단한 개요에는 [sketch-diagram](/docs/aws-content-plugin/skills/sketch-diagram)을 씁니다. 정확한 AWS 경계를 기록으로 남기려면 architecture-diagram을, 청중이 확대하고 이동하며 볼 다이어그램에는 Remarp `:::archify` 블록을 씁니다.

## 작성하는 내용 {#what-you-write}

장면은 데이터입니다. 영역, 부품, 연결선, 콜아웃, 인물, 단계를 나열한 객체 하나로 정의합니다. 0단계는 항상 전체 그림입니다. 아래 방향키를 누를 때마다 다음 단계를 한 번 재생하고 끝 상태를 유지하며, 위 방향키는 이전으로 돌아가고, 슬라이드를 나갔다 다시 들어오면 0단계로 초기화됩니다. 제공되는 템플릿(일반적인 요청 흐름 예시)은 그대로 빌드됩니다.

## 삽입 방법과 제한 {#embedding-and-limits}

슬라이드는 `@fit: off`를 쓰고, `:::html` 호스트 요소에 정적 대체 내용(한 문장과 단계 번호 목록)을 둡니다. 장면은 `:::script` 블록에서 마운트되어 이 대체 내용을 교체합니다. PDF 내보내기는 슬라이드 스크립트를 실행하지 않으므로 PDF에는 대체 내용이 나옵니다. 빌드는 장면 모듈과 참조한 AWS 아이콘을 덱에 복사하고, 브라우저가 `file://`에서 모듈 불러오기를 막으므로 http로 서비스해야 합니다. 목차의 ZIP 내보내기에는 장면이 포함되지 않으니, 빌드 디렉터리 전체를 공유하거나 호스팅하세요.

## 검증 {#verify}

덱을 검증하고 빌드한 뒤 서비스하여 라이트와 다크에서 모든 단계를 눌러 봅니다. 모션 줄이기가 켜져 있으면 누를 때마다 해당 단계의 끝 상태가 바로 보이고 이후에는 아무것도 움직이지 않아야 합니다.
