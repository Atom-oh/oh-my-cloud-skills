# GitBook 에이전트

README.md, SUMMARY.md, .gitbook.yaml, 주제별 페이지, 에셋과 상호 참조로 탐색하기 쉬운 GitBook 문서를 만듭니다.

## 작업 흐름 {#workflow}

페이지를 작성하기 전에 탐색 구조를 설계합니다. 독자에게 도움이 되는 곳에 GitBook 힌트, 탭, 제목이 있는 코드 블록, 펼침 섹션, 이미지, 다운로드와 임베드를 사용합니다. SUMMARY.md를 실제 파일과 맞추고 링크를 검증합니다. 요청된 경우에만 언어별 문서 트리를 추가하고 내용을 일치시킵니다.

## 결과물과 검증 {#output-and-verification}

편집 가능한 소스, 렌더링 결과, 관련 빌드 명령과 검증 근거를 제공합니다. 완료나 게시 전에 콘텐츠 리뷰 게이트를 통과해야 합니다. 파일을 저장했다는 사실만으로 리뷰를 통과한 것은 아닙니다.
