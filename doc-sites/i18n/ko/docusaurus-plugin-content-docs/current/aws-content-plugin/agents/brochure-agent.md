# 브로슈어 에이전트

상단 소개 영역, 가치, 기능, 삽입된 아키텍처와 명확한 행동 유도 문구로 구성된 단일 페이지 솔루션·제품 브로슈어를 만듭니다.

## 작업 흐름 {#workflow}

대상 독자와 핵심 가치를 확인하고 간결한 편집 레이아웃을 구성합니다. 실제 아키텍처를 통합하고 반응형 렌더링과 링크를 테스트한 뒤, 승인된 게시 전에 콘텐츠 리뷰를 수행합니다. 개인 포트폴리오에는 gh-home을, 여러 페이지로 된 문서에는 GitBook을 사용합니다.

## 결과물과 검증 {#output-and-verification}

편집 가능한 소스, 렌더링 결과, 관련 빌드 명령과 검증 근거를 제공합니다. 완료나 게시 전에 콘텐츠 리뷰 게이트를 통과해야 합니다. 파일을 저장했다는 사실만으로 리뷰를 통과한 것은 아닙니다.
