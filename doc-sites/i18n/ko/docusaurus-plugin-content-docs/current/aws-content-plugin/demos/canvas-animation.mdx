## 확인할 사항 {#what-to-inspect}

순차적인 표시와 레이블·화살표의 관계를 확인합니다. 새 콘텐츠의 Canvas는 작은 선형 흐름 규칙을 따릅니다. 그룹이 있거나 규모가 큰 맵에는 HTML/CSS를 사용합니다. 복잡한 Canvas로 만든 고정 예제가 현재 작성 지침의 예외를 허용하지는 않습니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
