## 확인할 사항 {#what-to-inspect}

정답과 오답을 각각 눌러 피드백과 상태를 확인합니다. 소스에서 [x]는 정답을, [ ]는 오답 선택지를 표시합니다. 정답이 여러 개인 문제에는 안내를 명시하고, 삽입된 퀴즈 구현이 실제로 무엇을 지원하는지 확인합니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
