## 확인할 사항 {#what-to-inspect}

시작·초기화 기능을 실행하고 트래픽, 복제본, 레이블과 범례의 변화를 확인합니다. 반복되는 흐름에는 SMIL을, 인터랙티브 확장·배포·장애 조치에는 상태 머신을 사용합니다. 이 고정 예제는 두 방식의 차이를 보여 줍니다. 새 다이어그램에는 현재 기준 토큰을 사용합니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
