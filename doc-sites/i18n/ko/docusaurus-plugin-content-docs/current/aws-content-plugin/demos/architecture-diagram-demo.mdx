## 확인할 사항 {#what-to-inspect}

내보낸 결과와 편집 가능한 Draw.io 소스를 함께 보관합니다. 새 다이어그램에는 기준 디자인 토큰 파일과 검증·레이아웃 게이트를 적용합니다. 고정 예제의 과거 아이콘 크기나 색상을 현재 토큰의 기준으로 삼지 않습니다. 최종 이미지에 잘린 셀, 겹침이나 오해를 부르는 그룹 경계가 없는지 확인합니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
