# 전체 프레젠테이션 데모

import DemoEmbed from '@site/src/components/DemoEmbed';

여러 블록으로 구성된 AIOps 심화 자료로 기획, 공유 테마 에셋, 편집 가능한 Remarp 소스, 탐색, 다이어그램과 이해도 확인을 설명합니다.

## 실행 예제 {#live-example}

<DemoEmbed
  src="/oh-my-cloud-skills/demos/aiops-deep-dive/index.html"

## 확인할 사항 {#what-to-inspect}

요청 정리 → 블록 계획 → 소스 → 검증 → HTML 빌드 → 상호작용 확인 → 콘텐츠 리뷰 순서로 진행합니다. 소스에서 대상 독자, 수준, 시간과 테마를 조정합니다. 공유 메타데이터는 _presentation.md에 두고 영향을 받는 블록을 다시 빌드합니다. 고정 예제의 콘텐츠는 원래 언어를 유지합니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
