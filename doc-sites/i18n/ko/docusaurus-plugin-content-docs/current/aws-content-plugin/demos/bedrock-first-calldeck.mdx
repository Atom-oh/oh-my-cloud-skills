## 확인할 사항 {#what-to-inspect}

이 덱은 과거 시점의 예제입니다. 포함된 모델 가용성, 가격과 서비스 설명은 당시의 예제 데이터입니다. 새 브리핑 자료에서는 해당 정보를 확인하고, 계산기의 가정을 테스트하며, Remarp를 검증하고 렌더링된 아키텍처를 확인한 뒤 리뷰합니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
