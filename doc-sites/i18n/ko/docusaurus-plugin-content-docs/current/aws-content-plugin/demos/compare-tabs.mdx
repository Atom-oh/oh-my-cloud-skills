## 확인할 사항 {#what-to-inspect}

각 선택 항목과 탭을 눌러 활성 상태와 표시 패널이 모두 바뀌는지 확인합니다. 간결하고 대등한 레이블과 동일한 비교 기준을 사용합니다. 새 소스에는 compare/tabs 유형을 명시하고 현재 프레임워크의 제어 기능을 사용합니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
