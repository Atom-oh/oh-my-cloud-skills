## 확인할 사항 {#what-to-inspect}

삽입된 버전이 지원하는 경우 Right/Space로 단계별 표시를 진행하고, O로 전체 보기를, P로 발표자 보기를 엽니다. 이 예제는 소스에서 HTML을 만드는 작업 흐름을 보여 줍니다. 새 덱에는 현재 런타임의 키보드 단축키 문서를 적용합니다.

삽입된 HTML, 다운로드 가능한 소스와 스크린샷은 변경하지 않는 예제 결과물입니다. 원래 언어를 유지하며, 이 가이드에서는 예제를 이해하는 방법을 설명합니다.
