# 문서 동기화 검사기

프로젝트 지침과 문서가 현재 코드, 명령, 의존성, 아키텍처와 일치하는지 분석합니다. 검사기는 누락된 모듈 컨텍스트, 오래된 참조, 문서화되지 않은 결정, 품질 공백을 감지합니다.

## 사용 {#use}

project-init의 `sync-docs` 워크플로를 실행하거나 범위를 정해 문서 점검을 요청합니다. 관련 소스 경로와 원하는 언어를 제공합니다. 검사기는 근거와 갱신안을 제시하지만, 보고서 자체가 변경 적용이나 테스트 완료를 입증하지는 않습니다.

## 보고 {#report}

영향받는 문서, 근거 소스 경로, 불일치, 구체적인 수정안을 명시합니다. 명령 사용성, 아키텍처 명확성, 간결성, 최신성, 실행 가능성을 평가합니다. 과거 점수를 영구적인 게이트로 삼지 말고 에이전트의 현재 평가 기준을 사용합니다.
