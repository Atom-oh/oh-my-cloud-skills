## What to inspect {#what-to-inspect}

Use the live demo as an output reference and the [quick-start example](../quick-start.md) for current English source. Each syntax feature has a dedicated guide; frozen embedded source may use older language, styling, or runtime behavior.

The example project reads its language from `_presentation.md`; the command writes a separate output directory. Embedded HTML, downloadable sources, and screenshots are frozen example artifacts. Their original language is preserved; these guides explain how to interpret them.
