## What to inspect {#what-to-inspect}

This is a dated sample deck. Model availability, pricing, and service claims inside it are historical example data. New briefings must verify those inputs, test calculator assumptions, validate Remarp, and inspect the rendered architecture before review.

Embedded HTML, downloadable sources, and screenshots are frozen example artifacts. Their original language is preserved; these guides explain how to interpret them.
