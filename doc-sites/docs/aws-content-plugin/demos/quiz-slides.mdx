## What to inspect

Click a correct and an incorrect option, then inspect feedback and state. In source, [x] marks an answer and [ ] a distractor. Use explicit instructions when a question has several valid answers and verify what the embedded quiz implementation actually supports.

Embedded HTML, downloadable sources, and screenshots are frozen example artifacts. Their original language is preserved; this wrapper documents how to interpret them in English.
