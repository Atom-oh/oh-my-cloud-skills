## What to inspect

Keep editable Draw.io source with the export. New diagrams use the canonical design-token file and validation/layout gates; historical icon sizes or colors in the frozen example are not the current token authority. Inspect the final image for truncated cells, overlap, and misleading group boundaries.

Embedded HTML, downloadable sources, and screenshots are frozen example artifacts. Their original language is preserved; this wrapper documents how to interpret them in English.
