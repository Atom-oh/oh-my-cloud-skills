## What to inspect

The workflow is brief → block plan → source → validation → HTML build → interaction checks → content review. Customize audience, level, timing, and theme in the source; keep shared metadata in _presentation.md and rebuild affected blocks. The frozen content remains in its original language.

Embedded HTML, downloadable sources, and screenshots are frozen example artifacts. Their original language is preserved; this wrapper documents how to interpret them in English.
