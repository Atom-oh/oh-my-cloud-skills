# Layout archetypes

Pick the layout from the natural shape of the topic, then bend it. Every archetype uses
the same parts (region, card, edge, dot, stamp), so they can be mixed, for example a
radial layout inside one band.

| Natural shape of the topic | Archetype | Notes |
|---|---|---|
| N parallel categories, options or phases, each with its own small flow | **Bands**: side by side washed panels, one stamp and centred title each | the template; works well at 3 bands |
| Top to bottom layers (client, service, storage) | **Layers**: full width washed rows, vertical edges crossing rows | keep rows to 3 or 4 |
| One core with several satellites | **Hub and spokes**: large central circle, nodes around it, radial edges | dots flow out, or in, never both on one spoke |
| Two or three things compared on the same dimensions | **Comparison**: side by side columns, same row means same dimension | no flow needed; use stamps and doodles |
| One main process | **Single path**: one snaking line across the canvas, cards on the bends | add a loop arc if the process repeats |
| Time | **Timeline**: horizontal line, event cards above and below alternately | dots travel along the line |

## Shape of the flow

Answer first: what flows, from where, through whom, where does it fork, merge, loop, end.
Then draw exactly that.

- Cycle, flywheel or retry in the topic: the main edge is a big arc around the outside,
  solid, with dots going round.
- Fan out or fan in: edges spread or converge, dots on every branch, offset in time.
- A picture with one row of same-direction arrows usually means the flow was not planned.
- Solid versus dashed encodes strength (certain versus weak, data versus control), never
  "main flow versus loop".

## Density

- Count nodes, annotations and arcs first, then derive geometry. Do not pick a height and
  fill it.
- Cards in a row fill the usable width: first card at the left padding, last at the right,
  equal gaps. Gaps are where arrows and short edge labels live.
- Every band needs at least one non-linear element (a stack of papers, a doodle person,
  a callout box with a dashed border, a loop arc). A band that is only boxes and arrows
  is unfinished.
- Leave natural empty space for one hand-written headline with a sparkle on each side.
