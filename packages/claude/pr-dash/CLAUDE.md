# pr-dash

A Claude Code mod plus one read-only skill. The mod (`hooks/hooks.json` →
`hooks/register.ts`) draws a pane, a status line and toasts for one pull request's CI
checks and AI review comment. `skills/pr-status` is the text equivalent for hosts and
surfaces that cannot draw (Codex, the VS Code chat panel, `claude -p`).

- Read-only toward GitHub: the mod runs `gh pr view` only. Buttons call
  `$.prompt.submit`; Claude's normal turn, permission prompts and the repository
  merge rules decide what happens. Never add a code path that merges, pushes,
  approves a tool call (`tool.check`) or denies one.
- `hooks/lib/*.ts` are pure functions; only `register.ts` touches `$`. Follow the mod
  validator's rules: full `$.ns.method` calls, literal event names, no `$`
  passed to imported functions, relative imports only.
- The review parser mirrors pr-autofix's trust rules (bot author + marker, first
  visible `**Status:**` line). It is display-only; CI stays the gate of record.
- `.claude-plugin/types/` is generated by Claude Code for the running build and is
  git-ignored. The mod is Claude-only; the Codex projection carries the skill.

Validate from this directory with `claude plugin validate .` and
`claude plugin test`. Regenerate the Codex package with
`python3 scripts/sync-codex-plugins.py --plugin pr-dash` from the repository root.
