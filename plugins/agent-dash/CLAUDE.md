# agent-dash

A Claude Code mod plus one read-only skill. The mod (`hooks/hooks.json` →
`hooks/register.ts`) draws a pane, a one-line band, a status line and notices for the
agents of the running session: who works, who delegated to whom, and who is waiting.
`skills/agent-status` is the text equivalent for hosts that cannot draw (Codex,
`claude -p`); it reads the agent-team roster files only.

- Read-only toward the session: never call `tool.check`, deny or approve a tool, rewrite
  a prompt, or change a `session.send`. The one exception is the `agent.spawn` model
  rewrite, off by default (`userConfig.modelPolicyEnabled`) and applied only when the
  spawn names no model. A model forced by the session still wins over it.
- The `agent.spawn`, `tool.call` and `session.send` observers return the chain's result
  unchanged and swallow their own failures. The task text, tool summaries and message
  text they keep stay in memory only: never logged, written or sent, pruned with the
  agent list, and not recorded at all with `userConfig.showDelegation` off. Redaction
  and truncation live in `hooks/lib/model.ts` (`redact`, `summarizeText`,
  `summarizeTool`, `recordTask`); store text only through those.
- A wait is an inference (a foreground child still running, or a message with no
  reply yet), never a fact the engine reports. Every surface labels it `est.`. A
  teammate in its own terminal pane has no loop here; its status may be stale.
- `hooks/lib/*.ts` are pure functions; only `register.ts` touches `$`. Follow the mod
  validator's rules: full `$.ns.method` calls, literal event names, no `$` passed to
  imported functions, relative imports only.
- Model policy values are aliases (`opus`, `sonnet`, `haiku`); never vendor model IDs.
- `.claude-plugin/types/` is generated by Claude Code for the running build and is
  git-ignored. The mod is Claude-only; the Codex projection carries the skill.

Validate from this directory with `claude plugin validate .` and `claude plugin test`.
Regenerate the Codex package with
`python3 scripts/sync-codex-plugins.py --plugin agent-dash` from the repository root.
