커스텀 풀은 다섯 줄이면 된다

Spot 배치 풀 NodePool 예시

nodepool-batch.yaml
apiVersion: karpenter.sh/v1
kind: NodePool
metadata:
  name: batch-spot
spec:
  template:
    spec:
      requirements:
        - key: karpenter.sh/capacity-type
          operator: In
          values: ["spot"]  # 중단 허용 워크로드 전용
      taints:
        - key: workload/batch
          effect: NoSchedule
  disruption:
    consolidationPolicy: WhenEmptyOrUnderutilized

전환 전 다섯 가지 점검

클릭해서 체크

  • 모든 Deployment에 PDB가 있는가 — 21일 교체 주기 무중단 흡수
  • 커스텀 AMI·userData 의존이 없는가 — 있다면 DaemonSet/사이드카로 이전
  • 노드 SSH에 의존하는 디버깅 runbook이 없는가
  • Spot 전용 NodePool과 taint 설계가 준비됐는가
  • 비용 태그 전략 — NodePool 단위 라벨로 Cost Explorer 분리
