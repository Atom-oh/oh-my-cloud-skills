워크로드 유형별 배치 전략

NodePool 선택 기준

general-purpose
기본 NodePool — On-Demand, 다양한 인스턴스 패밀리
별도 설정 없이 바로 스케줄링, 통합(consolidation)으로 유휴 노드 자동 회수
PDB 필수
노드 교체는 상시 — 최대 주 1회 AMI drift 교체 + 최대 수명 21일(기본 336시간=14일)
minAvailable + topologySpreadConstraints로 한 노드 교체가 한 replica만 건드리게
커스텀 NodePool + Spot
karpenter.sh/capacity-type: spot — 중단 허용 워크로드에 최대 90% 절감
Spot 회수 2분 통지는 컨트롤러가 처리 — Job은 backoffLimit·podFailurePolicy로 중단 재시도 처리
taint 분리
batch 전용 taint로 웹 워크로드 유입 차단
Job 쪽에는 toleration + nodeSelector를 함께 걸어 풀 밖으로 새지 않게
system NodePool
CriticalAddonsOnly taint — 애드온 전용 격리
CriticalAddonsOnly toleration + nodeSelector karpenter.sh/nodepool: system
과점유 주의
시스템 풀에 일반 워크로드 tolerate 금지
tolerations: operator: Exists 같은 광범위 설정이 가장 흔한 유입 경로
핵심 규칙 — 웹 서비스는 기본 풀로 충분하지만, PDB 없는 Deployment는 최대 주 1회 노드 교체마다 순단이 사용자에게 전달됩니다.
핵심 규칙 — Spot은 반드시 별도 NodePool로 분리하고, 체크포인트가 없는 긴 작업은 On-Demand 풀에 남겨 두세요.
핵심 규칙 — 시스템 풀은 건드리지 않습니다. 일반 워크로드의 tolerations를 admission 정책(Kyverno 등)으로 검사하세요.

Spot 풀은 네 블록이면 된다

Auto Mode용 karpenter.sh/v1 NodePool

nodepool-batch.yaml
apiVersion: karpenter.sh/v1
kind: NodePool
metadata:
  name: batch-spot
spec:
  template:
    spec:
      nodeClassRef: {group: eks.amazonaws.com, kind: NodeClass, name: default}
      taints: [{key: workload-type, value: batch, effect: NoSchedule}]  # 웹 워크로드 유입 차단
      requirements:
        - key: karpenter.sh/capacity-type
          operator: In
          values: ["spot"]  # 중단 허용 워크로드 전용
  disruption:
    consolidationPolicy: WhenEmptyOrUnderutilized
    consolidateAfter: 30s  # v1.0 CRD 필수 필드

점검 항목

확인 방법

  • 모든 Deployment에 PDB가 있는가 — 최대 주 1회 노드 교체를 무중단 흡수
kubectl get pdb -A — Deployment별 PDB 대조
  • 커스텀 AMI·userData 의존이 없는가 — 있다면 DaemonSet/사이드카로 이전
기존 EC2NodeClass spec.userData·amiSelectorTerms 사용 여부 — kubectl get ec2nodeclass -o yaml
  • 노드 SSH에 의존하는 디버깅 runbook이 없는가
NodeDiagnostic — 노드 로그를 S3로 수집, SSH 없는 runbook으로 교체
  • Spot 전용 NodePool과 taint 설계가 준비됐는가
kubectl get nodepools -o yaml — Spot 풀·taint·system 풀 구성 확인
  • 비용 할당 태그 eks:kubernetes-node-pool-name 활성화
Billing 콘솔의 비용 할당 태그 화면 — 활성화 여부 확인
